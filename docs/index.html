02 · Safety model

Every request.
Same pipeline.

  • 01
    Circuit breakerBlocks everything after 2 errors, or one 401 / 403 / 429.
  • 02
    Rate limiter50 reads / 15 min, 15 writes / hour, spaced 3–6 s and 15–30 s.
  • 03
    One attemptSingle HTTPS call, 35 s timeout. Never retried, never duplicated.
  • 04
    Clear signalexit 0 ok · exit 4 wait & retry once · exit 2/3 halt & tell the user.

    04 · For AI agents

Install prompt


Install the x-use CLI for me and set it up as a skill.

1. Run `node --version`. If it is older than 20.19, stop and tell me.
2. Install and test:
   git clone https://github.com/dalroot/x-use.git
   cd x-use && npm install && npm test && npm link
3. Copy x-use/SKILL.md into your skills folder
   (Claude Code: ~/.claude/skills/x-use/SKILL.md), read it fully
   and follow its rules from now on.
4. Never ask for, read, print or store my X cookies.
   Tell me to run this myself in my own terminal:
     export X_USE_KEY="my-long-passphrase"
     xuse setup --cookies ./cookies.json --encrypt
     rm ./cookies.json
   and to make X_USE_KEY available in your environment.
5. When I confirm, run `xuse check --json` and
   `xuse limits --json` and show me the results.

Rules: always use --json. If the output has "halt": true,
stop and report the exact error. If "pacingWait": true, wait
waitSeconds and retry once. Never reset the breaker or limits,
never edit ~/.x-use/, run one command at a time, and ask me
before any tweet, reply, thread, like, retweet or delete.
